substrata Documentation
=======================

Welcome to the substrata documentation!

substrata is a Python package for 3-D geometry and point-cloud handling, providing
utilities for working with point clouds, camera calibration, annotations, and
geometric transformations.

Getting Started
---------------

If you're new to substrata, check out the following resources:

* :doc:`notebooks/getting_started` - A comprehensive introduction to substrata
* :doc:`notebooks/command_line_usage` - Learn how to use the command-line interface
